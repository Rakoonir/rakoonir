## 📡 `> cat about.md`

Selfhoster, server enthusiast and hobby gamer, somewhere between the server rack
and the gaming setup. I build infrastructure, manage servers, and spend nights
discovering new technologies — from containers to custom kernels.

Linux and open-source software are my passion. I firmly believe: **you should
know and control your own infrastructure — instead of blindly handing it over
to someone else.**

```diff
+ Selfhoster
+ Gamer
+ Designer
+ Clan Founder
```

Since June 2025 I've also been volunteering as part of a federal volunteer
service at [**Oldenburger Tafel e.V.**](https://www.oldenburger-tafel.de/) — goods
handling, warehouse management, and on-site IT support. Running servers and
helping people aren't mutually exclusive. 🥫
